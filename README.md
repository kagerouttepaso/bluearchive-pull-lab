# ブルアカ募集期待値ラボ

ブルーアーカイブの旧交換方式と新チャージ方式を、同じ青輝石予算・総募集回数・目標のPU生徒が全員そろう確率・平均獲得回数で比較する非公式計算ツールです。

GitHub Pagesで公開する、静的な単一ページアプリです。

## 主な内容

- 1〜4人の異なるPU生徒を全員確保できる確率
- 全員確保までの平均、中央値、90%・95%ライン、最悪保証
- PU獲得回数と★3獲得回数の期待値
- 目標のPU生徒が何人そろうかを示す確率分布
- 交換・保証・重複を含め、PUを合計何回獲得するかを示す確率分布
- 全員そろう確率（全員確保率）と期待値が答える問いの違い
- 旧仕様のウィニングランと、新仕様で1人確保するまでの早さの比較
- 数字上の得と、ガチャを引くときの安心感・高揚感が両立しない場合の説明

## Prerequisites

- Node.js `>=22.13.0`

## ローカル実行

```bash
npm install
npm run dev
npm run build
```

## コマンド

- `npm run dev`: 開発サーバーを起動
- `npm run build`: アプリのビルドを検証
- `npm test`: ビルド後のHTMLを検証
- `npm run build:pages`: GitHub Pages用の静的ファイルを生成

## 計算前提

既定値は★3率3.0%、選択中PU率0.7%です。新仕様は100チャージで★3確定かつ50%でPU、200チャージでPU確定、PU獲得時にチャージをリセットするモデルです。異なるPUを狙う場合は、1人確保するたびに次のPU募集へ切り替えます。

本サイトは非公式です。実際の募集条件はゲーム内表示と[公式告知](https://bluearchive.jp/news/newsJump/679)を確認してください。
